# 2026-05-29 Skill Audit

## Objective

Audit the canonical personal skill inventory in `../CodexSkills/.agents/skills`, select the strongest public-facing candidates, and package them into this repo as portfolio-quality product artifacts.

## Working Assumption

Because the audience split was still unanswered, this pass assumes `both with hiring-first positioning`:

- the repo should feel useful to real users on its own
- the curation should also demonstrate product judgment, AI workflow design, and engineering discipline

## Public Selection Rubric

Each candidate was evaluated against five questions:

1. Is the value legible without private repo context?
2. Can the skill stand alone as an installable artifact?
3. Is the workflow broadly useful outside Dioscuri-specific projects?
4. Does the public copy avoid fragile internal dependencies, credentials, or proprietary state?
5. Does publishing it strengthen the portfolio story of disciplined AI-product work?
